# KShot

KShot 是一个轻量、原生的 macOS 截图标注工具，作者：范显。

## 第一版能力

- 全局快捷键 `⌃⌘A`
- 多显示器冻结画面与手动框选
- 实时显示像素尺寸
- 矩形、箭头、文字和马赛克标注
- 拖动选区、八方向调整选区
- `Esc` 取消，`Enter`、双击或工具栏勾号完成
- 完成后自动写入系统剪贴板
- 内置百度 PP-OCRv6 tiny 模型，本地识别选区文字并自动复制结果
- 截图后可启用文字识别工具，在选区内拖过文字并松手复制

## 运行

需要 macOS 13 或更高版本以及 Xcode 15 或更高版本。

```bash
make run
```

第一次截图时，macOS 会请求“屏幕与系统音频录制”权限。授权后如果仍然无法截图，请退出 KShot 并重新运行。

也可以直接双击 `Package.swift`，在 Xcode 中选择 KShot Scheme 运行。

## 操作

1. 点击菜单栏取景框图标，或按 `⌃⌘A`。
2. 拖动鼠标框选截图区域。
3. 可拖动选区内部移动选区，或拖动八个控制点调整大小。
4. 从工具栏选择标注工具；再次点击已选中的工具可回到选区移动模式。
5. 点击蓝色文字取景框按钮，再在截图内拖过目标文字；松手后自动识别并复制。
6. 按 `Enter`、双击选区或点击绿色勾号完成，图片会进入剪贴板。

按 `Delete` 可撤销最近一条标注。

需要复制图片文字时，先正常框选截图，再点击蓝色文字取景框按钮。按钮高亮后，在截图内部拖过目标文字，松开鼠标即可自动识别并写入剪贴板。

OCR 使用百度 PaddleOCR 开源的 PP-OCRv6 tiny 模型和 ONNX Runtime，全部在本机运行，无需 API Key，也不会上传截图。
