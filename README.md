# KShot

KShot 是一个轻量、原生的 macOS 截图标注工具，作者：范显。

## 第一版能力

- 全局快捷键 `⌃⌘A`
- 多显示器冻结画面与手动框选
- 实时显示像素尺寸
- 矩形、箭头、文字和马赛克标注
- 拖动选区、八方向调整选区
- `Esc` 取消，`Enter`、双击或工具栏勾号完成
- 完成后自动写入系统剪贴板
- 使用智谱 Coding Plan 视觉模型识别选区文字，并自动复制识别结果
- `⌃⌘X` 进入划词识别，拖过文字并松手即可复制

## 运行

需要 macOS 13 或更高版本以及 Xcode 15 或更高版本。

```bash
make run
```

第一次截图时，macOS 会请求“屏幕与系统音频录制”权限。授权后如果仍然无法截图，请退出 KShot 并重新运行。

也可以直接双击 `Package.swift`，在 Xcode 中选择 KShot Scheme 运行。

## 操作

1. 点击菜单栏取景框图标，或按 `⌃⌘A`。
2. 拖动鼠标框选截图区域。
3. 可拖动选区内部移动选区，或拖动八个控制点调整大小。
4. 从工具栏选择标注工具；再次点击已选中的工具可回到选区移动模式。
5. 点击蓝色文字取景框按钮，可识别选区文字并复制到剪贴板。
6. 按 `Enter`、双击选区或点击绿色勾号完成，图片会进入剪贴板。

按 `Delete` 可撤销最近一条标注。

智谱 Coding Plan Key 可通过菜单栏 KShot 图标中的“智谱 OCR 设置…”保存。Key 仅存放在 macOS 钥匙串，不会写入项目文件。

需要快速复制图片文字时，按 `⌃⌘X`，直接拖过目标文字；松开鼠标后会自动识别并写入剪贴板。
